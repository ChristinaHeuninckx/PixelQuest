# Wat is het verschil tussen Watch, Star en Fork?
Watch is je kan kiezen als de devs worden genotified als er iets verandered is
Star is je fav of important repository vinken
Fork is een copy van je repository om te experimenteren

# Waarom zijn Issues nuttig in een softwareproject?
om taken te verdelen of te zien als het klaar is of als er een bug is of iets moet afmaken

# Hoe helpen Labels en Milestones bij projectbeheer?
Labels kan je een issue labelen om te tonen wat de issue erover gaat en milestones om te tonen of zien als de dingen afgemaakt zijn of "reached the goal"

# Waarom controleer je een Pull Request voor je die merge?
Om te checken als er geen fouten zijn of anders krijg je een merge issue

# Wat is het verschil tussen Raw, History en Blame?
Raw om te file te zien
history om te zien wat je alemaal heb gedaan, bv de commits
blame kan je zien wie heb iets gedaan of veranderd

# Wanneer zou je een Wiki gebruiken in plaats van een README?
Je kan meer structuur geven in een wiki en meerdere paginas insteken, in README kan je dat niet doen

# Wat doet GitHub Pages?
Je kunt gratis een live page maken
